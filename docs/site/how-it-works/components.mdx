---
title: Main Components
description: The main services and on-chain state used by Dugong.
---

- **Web app**: handles search, X sign-in, wallet linking, and dashboards.
- **API**: serves app requests, receives webhooks, and coordinates processing.
- **Nautilus service**: handles enclave-facing processing for protected flows.
- **Indexer**: mirrors Sui events into the app database for fast reads.
- **On-chain state**: stores Dugong account and transaction records on Sui.
