# Dugong Docs

Dugong lets people use an X identity as the entry point to a Sui wallet. A
Dugong account can be discovered by handle, linked to a wallet, and used by the
backend services to coordinate sponsored Sui transactions.

## What You Can Do

- Search for a Dugong account by X handle, X user id, or Sui object id.
- Sign in with X to view your own dashboard.
- Link a Sui wallet to your Dugong account.
- Track account activity and on-chain transaction state.
