Dugong is organized around an account that connects an X identity to on-chain
Sui activity. The app is designed for quick lookup first, then authenticated
account management.

## Main App Areas

- [Account Search](./account-search.mdx) covers public lookup by X handle, X user id, or Sui object id.
- [Dashboard](./dashboard.mdx) covers the signed-in account view.
- [Wallet Linking](./wallet-linking.mdx) covers linking an external Sui wallet.
- [Transactions](./transactions.mdx) covers transaction state and history.

Tweet-driven flows live in [Tweet Commands](../tweet-commands/index.mdx).
