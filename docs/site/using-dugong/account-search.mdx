---
title: Account Search
description: Search for Dugong accounts by X handle, X user id, or Sui object id.
---

The home page search is public. You can use it to find a Dugong account by X
handle, X user id, or Sui object id.

Search results open a read-focused account view so another person can inspect
account state without signing in.

Accepted inputs:

- an X handle, such as `@dugongwallet`
- an X user id
- a Sui object id beginning with `0x`
