---
title: Prediction Markets
description: Create markets, place predictions, resolve outcomes, and handle payouts.
---

## Create A Market

Use this to create a prediction market.

```text
@DugongWallet create market: <question>
```

Example:

```text
@DugongWallet create market: Will Sui testnet stay healthy today?
```

Behavior:

- Creates a market anchored to the command tweet id.
- Stores the tweet author as the market creator.
- Uses the default market fee configured in the processor flow.
- Replies with the market question, prediction instructions, resolve instructions, and a Suiscan transaction link.

## Place A Prediction

Use this as a reply to the market creation tweet.

```text
@DugongWallet predict <amount> <coin> on yes
@DugongWallet predict <amount> <coin> on no
@DugongWallet predict <amount> <coin> with yes
@DugongWallet predict <amount> <coin> with no
```

Examples:

```text
@DugongWallet predict 1 DUG on yes
@DugongWallet predict 0.25 SUI with no

(`bet` is still accepted as a legacy alias for backward compatibility.)
```

Behavior:

- Finds the market from the parent tweet id.
- Auto-creates the predictor's Dugong account if needed.
- Escrows the stake in the market pool.
- Replies with a prediction confirmation and Suiscan transaction link.
- If the market is missing, replies that no market was found for the tweet.
- If the market is closed, replies that predictions are no longer accepted.

## Resolve A Market

Use this as a reply to the market creation tweet.

```text
@DugongWallet resolve yes
@DugongWallet resolve no
@DugongWallet solve yes
@DugongWallet solve no
```

Behavior:

- Only the market creator can resolve the market.
- Resolves the market for each coin type that has bets.
- Pays winning bettors automatically. If a side has no winning bettors for a coin pool, the payout logic refunds eligible bettors for that pool.
- Replies with the winning outcome, number of paid winner entries, and the last Suiscan transaction link.
- If the resolver is not the creator, replies that only the creator can resolve the market.
- If the market is missing or already closed, replies with the matching error message.
