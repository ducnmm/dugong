title: Tweet Commands
description: Commands Dugong supports when a tweet mentions the bot handle.
---

Dugong supports tweet-driven commands when a tweet mentions the bot handle
before the command keyword. The examples below use `@DugongWallet`.

Supported coin symbols in tweet commands are `DUG`, `SUI`, `WAL`, and `USDC`.
`CORE` is still accepted as a legacy alias for `DUG`.

## Supported Commands

- [Account Creation](./account-creation.mdx)
- [Transfer](./transfer.mdx)
- [Prediction Markets](./markets.mdx)
- [Reward Campaigns](./rewards.mdx)
- [Claim](./claim.mdx)
- [System Replies](./system-replies.mdx)
